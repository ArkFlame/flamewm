# FlameWM Routes

Load mapped skills before substantive work. Use local canonical IDs only.

| Route | Load | Capability / trigger |
| --- | --- | --- |
| All FlameWM work | `flamewm-source-first` | Source, callers, contracts, and owners first. |
| Parallel independent work | `flamewm-parallel-execution` | Non-overlapping claims only; one owner per path. |
| Architecture or feature boundary | `flamewm-semantic-modularization` | Extend canonical typed owner; route planner when ownership or design is unresolved. |
| Rust ownership, events, FFI | `flamewm-rust-systems` | Rust complement required for Rust changes, including planner-routed work. |
| X11 WM, ICCCM, EWMH, grabs | `flamewm-x11-window-manager` | WM authority and coordinate/lifetime rules. |
| Historical corpus needed | `flamewm-reference-mining` | Mine `.vendor/**` as evidence only. |
| Failure or failed repair | `flamewm-failure-resolution` | Exact diagnostics; failed repair escalates competing hypotheses. |
| Native behavior/integration claim | `flamewm-runtime-evidence` | Fresh direct runtime proof; no static substitute. |
| Performance claim/tuning | `flamewm-performance-proof` | Repeatable baseline, metric, and retained evidence. |
| Release/package/readiness | `flamewm-release-proof` | Fresh build, artifact, identity, and runtime evidence. |

## Agent Caps

| Agent | Cap |
| --- | --- |
| `flame-coordinator` | Read-only routing; serialize all Cargo work. |
| `flame-researcher` | Read-only source and hypothesis evidence. |
| `flame-rust-reviewer` | Read-only Rust correctness review. |
| `flame-repair` | Assigned-path minimal edits; no shell. |
| `flame-runtime-verifier` | Bounded runtime commands; no edits; isolated display only. |
